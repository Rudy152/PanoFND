# PanoAgent v2 消融实验总览（2026-11-26）

本文汇总到目前为止做过的全部消融：它们依据什么设计、各回答什么问题、结果如何、还缺什么。细节见各分报告，文件索引在文末。

## 1. 设计依据

### 1.1 按 v2 的模块拆，一张表对应一个模块

消融不是挑几个变体随便试，而是**沿着 v2 架构逐层拆**。v2 的数据流是：

```
L0 媒体规范化（读入、转码、抽帧、缩放、加附件标签）
   ├→ L1 CLIP 合成图像检测器 ───────────┐
   ├→ L2a 单次调用：直接问 TRUE/FALSE ──┼→ 17 个特征 → L4 逻辑回归打分器 → 标签和概率
   └→ L2b 证据智能体：两两比较 + 单模态审查 ┘
```

每一层都设计了对应的消融：

| 模块 | 要回答的问题 | 消融 | 是否调用 API |
|---|---|---|---|
| 各模块整体 | 每个模块去掉后损失多少；只留一个模块够不够 | 表 A | 否 |
| L2b 内部 | 智能体的哪类证据（一致性、槽位、完整性、单模态审查）、哪个模态对在起作用 | 表 B | 否 |
| L4 打分器 | 训练出来的打分器是否比固定规则、单一阈值、梯度提升树更好 | 表 C | 否 |
| L2b 的结构 | 两两比较是否优于一次看全部模态 | 表 D 的 D1 | 是 |
| L0 和提示词 | v2 相对 v1 的 8 处输入改动各贡献多少 | 表 E | 是 |
| 基础模型对照 | 基础模型也调门槛，和 v2 的比较是否更公平 | 评测集基线 | 是 |

没有消融的部分及原因：L3 检索在 v2 中没有启用，没有东西可去掉；定位输出没有人工标注，无法评测；哈希缓存、子进程解码、补跑是工程措施，不影响预测。

### 1.2 共同原则

1. **以冻结的 v2 为参照，不改它。** 8 个冻结文件的哈希在每次实验前后都核对过，消融代码全部写在新模块里。
2. **一次只改一个因素。** 表 E 每个变体只改一项输入，模型、系统提示词、温度、seed 都不变，只重跑请求内容真正改变的样本。这样差值可以归到这一项上。
3. **只用 943 条调参集。** 765 条评测集此前已经看过多次，不用于任何消融或选择。程序遇到评测集划分会直接退出。唯一的例外是导师要求的基础模型调门槛基线：门槛先在调参集上冻结，再在评测集上跑一次，不据此选择任何东西。
4. **免费的先做。** 表 A 到 C 只用缓存的特征重新训练打分器，不调用 API；表 D、E 每次花钱前都单独确认。
5. **事先定下主要对比，其余都是探索性。** 方案里定了 4 个主要对比，一起做 Holm 校正：原声（R 对 −A2）、提示词（R 对 −P）、附件标签（R 对 −L）、结构（两两比较对 D1）。其余对比都没有校正，只用于解释。
6. **控制模态组合带来的标签信息。** 只用 9 种模态组合，Balanced Acc. 就有 58.6%。所以表 A 到 C 的每个系统都报告"原样"和"加模态组合"两列，避免把模态信息误当成模块的作用。
7. **控制重跑噪声。** 温度 0 加固定 seed 并不能复现：同一请求重跑，P(fake) 平均差约 0.065，4% 到 8% 的样本在 0.5 处翻转。因此表 E 先把 180 条原样重跑两次（N、N2），设置漂移门槛，再估计"重跑带"。差值必须区间不含 0、且大于重跑带，才算"能分辨"。

### 1.3 统计方法

- 主指标 AUROC，次指标 Balanced Acc. 和 Macro-F1。
- 打分器一律用嵌套、按来源分组的交叉验证：外层 5 折，内层 4 折，换 10 个划分种子取平均。
- 配对差值用按来源组（427 组）的聚类 bootstrap。评测集上的比较用按标签分层的配对 bootstrap。
- 失败样本：主分析只用两边都成功的样本，另外报告把失败计为 0.5 的结果。

## 2. 结果一览

| 实验 | 结论 | 可信程度 |
|---|---|---|
| 表 A：去掉智能体（L2b） | Balanced Acc. 降 3.3 个点 [1.8, 4.9]；加模态组合后仍降 3.4 [1.7, 5.1] | 调参集上成立，但**评测集没有复现**（+0.2 [−2.0, +2.6]） |
| 表 A：去掉 L1 检测器 | 没有测到作用 | 探索性 |
| 表 B：智能体内部 | 完整性判断最重要；一致性次之；槽位和单模态审查没有测到作用 | 探索性 |
| 表 B：模态对 | text-audio 影响最大，但各模态对的比较不完全公平 | 探索性 |
| 表 C：打分器 | 训练出的打分器比"任一冲突即判假"的固定规则高 9.9 个点 | 探索性 |
| D1：两两比较对一次看全部 | AUROC +0.021 [+0.003, +0.038]，Holm 校正后 p = 0.030；Balanced Acc. 无差别；一次看全部便宜约 42% | 通过校正，但幅度小，可能被跨日偏移高估 |
| 表 E：听原声对转写稿 | AUROC +0.114 [+0.091, +0.136]，Holm 后 p = 0.004 | **最稳固** |
| 表 E：v2 提示词 | AUROC +0.022 [+0.008, +0.034]，Holm 后 p = 0.006 | 通过校正；换成同日参照后不再显著 |
| 表 E：附件标签 | AUROC +0.018 [+0.004, +0.031]，Holm 后 p = 0.030 | 同上 |
| 表 E：转写稿截断、视频音轨、16 帧、原分辨率、发布日期 | 都未能分辨 | 这些设计既没有得到支持，也没有被否定 |
| 表 E：去掉标题（无文本模态的样本） | AUROC +0.043 [+0.008, +0.078]，主要来自纯图片 | 探索性 |
| 表 E：完整 v1 请求（S0） | AUROC 低 0.092；六项单独改动之和为 0.074，剩余 0.018 | 探索性 |
| 基础模型调门槛（评测集） | 70.3%，比直接回答的 70.9% 还低；v2 单次调用调门槛比它高 13.1 [+9.9, +16.4] | 门槛事先冻结，评测集只跑一次 |

## 3. 回应导师的建议：12.7 个点的来源

评测集 765 条上的 Balanced Acc.：

| 步骤 | Balanced Acc. | 增量 [95% CI] |
|---|---:|---:|
| 基础模型直接判断 | 70.9% | — |
| 改材料和提示词，仍直接判断 | 79.3% | +8.5 [+5.5, +11.4] |
| 调参集上调判假门槛 | 83.4% | +4.1 [+1.8, +6.3] |
| 加两两比对和打分器 | 83.6% | +0.2 [−2.0, +2.6] |

基础模型也调门槛后得到下面的 2×2 表：

| | 不调门槛 | 调参集门槛 |
|---|---:|---:|
| v1 输入 | 70.9%（直接回答）/ 72.8%（P ≥ 0.5） | 70.3% |
| v2 输入 | 79.3%（直接回答）/ 80.2%（P ≥ 0.5） | 83.4% |

- **调门槛只对 v2 输入有用**，因为 v2 输入直接回答时偏向判真（REAL 召回 92%，FAKE 召回 66%）。基础模型调门槛反而低 2.6 个点。
- 因此第二步的贡献取决于先后顺序：先改输入再调门槛，是 +8.5 和 +4.1；反过来是 −0.6 和 +13.1。论文里应把这两步合起来写成"输入和提示词的设计及与之配套的门槛"，并附上 2×2 表。
- 第一步的内部来源由表 E 在调参集上拆开：最大的是听原声，其次是提示词和附件标签。
- 第三步只多 0.2 个点，不能说成多步推理带来的提升。调参集上智能体有约 3 个点的作用，但评测集没有复现，两者都要如实报告。

## 4. 限制

- 943 条调参集也用于过设计和调参，所以消融结果用来解释差别，不用来证明泛化。参照 R 是在这批数据上选定的，可能对 R 有利。
- 每个 API 变体只跑一次。参照是 11-21/22 跑的，D1 和表 E 是 11-24/25 跑的。同一请求的两次重跑都比原参照的 AUROC 低约 0.01，所以小效应（提示词、标签、D1）可能被高估约 0.01 到 0.02。
- 原声的优势可能部分来自数据集的制作痕迹（合成语音、编码、响度等），尚未检验。转写稿来自数据集自带的文本，质量没有核对。
- 模态组合带有标签信息；"纯图片""纯音频"样本其实都带标题。
- 视频类变体只有约 240 条，±0.04 以内的作用测不到。
- 评测集已经看过多次，基础模型调门槛的基线又看了一次。
- 方案里的 D2（同调用次数的重复单次调用，约 9.2 元）没有做，所以"智能体的作用是否只是因为多调用了几次"还没有回答。
