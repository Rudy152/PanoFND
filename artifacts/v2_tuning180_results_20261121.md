# PanoAgent v2：180 条调参子集实验（2026-11-21）

## 实验设置
- 样本：`splits/v2_tuning180_seed42_20261121.json`，从 943 条调参集中抽取，真假 × 9 种模态每格 10 条，与 765 条最终测试集没有重叠。其中包含 11/07 用过的 90 条。
- 基础模型：qwen3.8-omni-flash。音频直接输入原声，每个媒体都带标签，视频抽 8 帧并附带音轨。
- 打分：嵌套交叉验证，按新闻来源分组并按标签分层，外层 5 折、内层 4 折。每条样本的预测都来自没见过它的模型。
- 用量：180/180 条完成，没有致命错误；约 350 次证据调用中有 4 次 JSON 无效；共 219 万 tokens。

|---|---:|---:|---:|---:|---:|---:|

配对 McNemar 检验：
- v2 对比 v1 单次调用：只有 v2 判对 27 条，只有 v1 单次调用判对 8 条，**p = 0.002**，差异显著。
- v2 输入的单次调用对比 v1 输入的单次调用：25 对 10，**p = 0.017**，差异显著。
- v2 对比 v2 输入的单次调用：11 对 7，**p = 0.48**，差异不显著。

## 结论
1. 和原来的单次调用相比，v2 的 Balanced Acc. 高出 10.5 个百分点，而且差异显著。
2. 提升主要来自输入的改进：原声音频加带标签的媒体，就把单次调用从 67.8% 提到了 76.1%，差异显著。提升集中在含音频的组合上，例如 text+image+audio 从 50% 升到 65%，audio+image 从 55% 升到 75%。这印证了评审意见第 2 点：只给转写稿是主要短板。
3. 两两比较加打分器，在相同输入的单次调用基础上只多了 2.2 个百分点，差异不显著。只用两两比较证据（79.4%）和单次调用的效果相当，说明这些证据有信息量，但还没有证明它能带来额外增益。text+audio（70% → 85%）和 text+image+audio（65% → 75%）是例外。
4. CLIP 零样本检测器没有帮助，去掉它反而略好。这与预期一致：它对图表这类本身像合成图的图片会误判。
5. 最终模型中权重最大的特征依次是：单次调用的假新闻概率、是否有模态被判为篡改、完整性判断为"不确定"的比例，以及"内容无关"的比例。

## 注意事项
- 样本只有 180 条，各组之间的置信区间有重叠，按模态的结果每组只有 20 条，波动很大。
- 这是调参集上的结果，不是最终测试结果。
- 定位准确率（预测的被篡改模态是否与标注一致）还没有计算。
