# 消融实验方案：按 v2 模块组织（2026-11-24 第二版）

> 2026-11-26 状态：表 A、B、C、D1、E 已完成，D2 没有做。结果汇总见 [ABLATION_SUMMARY_20261126.md](ABLATION_SUMMARY_20261126.md)。下面是执行前写定的方案，没有按结果修改。

只用 943 条调参集。765 条最终测试集已经看过多次，这里不再使用。

## 0. 模块与消融的对应

```
L0 媒体规范化 → L1 CLIP 检测器 ┐
             → L2a 单次调用    ├→ 17 个特征 → L4 打分器 → 标签、概率、定位
             → L2b 证据智能体  ┘
```

| 模块 | 消融内容 | 表 | 费用 |
|---|---|---|---|
| 全部 | 逐个去掉模块 | 表 A | 免费 |
| L2b 智能体内部 | 逐组去掉一致性、槽位、完整性、单模态审查 | 表 B | 免费 |
| L4 打分器 | 换成固定规则、单一阈值、浅层梯度提升树 | 表 C | 免费 |
| 模态信息 | 每个主要系统加或不加模态组合 | 表 A、B、C 都报告 | 免费 |
| L2b 的结构 | 两两比较对一次性看全部模态；同调用次数的重复单次调用 | 表 D | 约 13 元 |
| L0 和提示词 | 每次只改一项输入 | 表 E | 约 22 元 |

- L3 检索在 v2 中没有启用，没有可以去掉的东西。v1 上 90 条的检索对照只能在文中提及，不能算 v2 的消融。
- 定位输出没有现成标注，无法消融，等人工标注后再做。
- 哈希缓存、子进程解码、补跑是工程措施，不影响结论，不做消融。

## 1. 设计前已知的事实（调参集离线计算，未调用 API）

1. **标题按文本处理。** 音频、图片、音频+图片三类共 277 条，v1 和 v2 都给了标题。所以"纯图片"是"图片+标题"；`has_text` 在 943 条里有 942 条为 1；只有 66 条纯文本样本做单模态审查。
2. **两两比较只在三个模态的样本上才与"一次看全部"不同。** 两个模态的样本只有一对，两种做法看到的内容相同。三个模态（标题算文本）的共 421 条：audio+image 123、text+image+audio 151、text+image+video 147。结构消融只对这 421 条有意义。
3. **模态组合带有标签信息。** 只用 9 种模态组合，Balanced Acc. 为 58.6%。单次调用加模态独热、不用智能体，为 82.1%；单次调用为 78.9%，v2 全部特征为 83.0%，智能体特征加模态独热为 84.6%。这些差值没有做显著性检验。（2026-11-24 补充：表 A 跑完后，两边都加模态组合时智能体仍有约 3 个点的作用，见 [ablation_abc_results_20261124.md](ablation_abc_results_20261124.md)，所以不能说增益主要来自模态信息。）
4. **v1 的转写稿被截断到 8,000 字符。** 462 条含音频样本里有 425 条超过。
5. **v1 和 v2 的单次调用有 8 处不同：** 提示词和排版、附件标签、音频形式、视频帧数、音轨、图片分辨率、模态声明、输出形式。

## 2. 表 A：逐个去掉模块（免费）

每一行都在 943 条上做嵌套、按来源分组的交叉验证。每个系统算两列：**原样**（v2 的 `has_*` 特征）和**加模态独热**。

| 编号 | 系统 | 说明 |
|---|---|---|
| A0 | 完整 v2 | 参照 |
| A1 | −L1 | 去掉 `image_synth_max`、`frame_synth_max` |
| A2 | −L2a | 去掉 `single_p_fake` |
| A3 | −L2b | 去掉全部智能体特征 |
| A4 | 只有 L2a | 单次调用，交叉验证阈值 |
| A5 | 只有 L2b | 智能体特征 |
| A6 | 只有 L1 | 检测器特征 |
| A7 | 只有模态 | 模态组合，作为下限 |

已有的部分结果（原样一列）：A0 83.0%，A1 82.6%，A2 82.4%，A4 78.9%，A5 82.8%，A7 58.6%。A3、A6 和全部"加模态独热"列要新算。

说明：`failed_calls` 反映的是网络和内容审核，不是新闻内容，A0 到 A6 再各报告一次去掉它的结果。

## 3. 表 B：智能体内部（免费）

从 A0 和 A5 各去掉一组：

| 编号 | 去掉的特征 |
|---|---|
| B1 一致性 | `frac_conflict`、`frac_unrelated`、`any_conflict` |
| B2 槽位 | `slot_mismatch`、`slot_match` |
| B3 完整性 | `frac_manipulated`、`any_manipulated`、`frac_integrity_uncertain` |
| B4 单模态审查 | `uni_contradictory`（只有 66 条样本有取值，预计测不出来） |

再按模态对单独去掉一种：text-image、text-audio、image-audio、text-video、image-video，重新由缓存的调用结果计算特征，不需要新的 API 调用。

## 4. 表 C：L4 打分器（免费）

固定特征，只换打分方式：

| 编号 | 打分方式 |
|---|---|
| C0 | 逻辑回归，`class_weight=balanced`，内层选 C 和阈值（现有） |
| C1 | 固定规则：任一冲突或篡改即判假（已有 72.8%） |
| C2 | 只用单次调用分数，每个模态组合各自选阈值 |
| C3 | 浅层梯度提升树，超参数只在内层选 |
| C4 | 逻辑回归，阈值固定为 0.5 |

## 5. 表 D：智能体的结构（需要 API，约 13 元）

| 编号 | 内容 | 条数 | 预计 tokens | 费用 |
|---|---|---:|---:|---:|
| D1 | 一次调用看全部模态，输出每一对的一致性、槽位和每个来源的完整性，转成同样的特征 | 421 | 输入约 3.5M，输出约 0.2M | 约 3.4 元 |
| D2 | 同调用次数的重复单次调用：2 次的样本多 1 次，4 次的多 3 次，用改写过的提示词，取平均概率 | 943 | 约 11.5M | 约 9.2 元 |

- D1 对完整 v2 的比较只在这 421 条上有差别，其余 522 条直接沿用两两比较的缓存结果。D1 的提示词要求与两两比较相同的枚举值，输出上限设为 1,500 tokens（两两比较为 700，有调用达到上限）。
- D2 回答"智能体的作用是不是来自多调用几次"。温度为 0，重复同一提示词会得到相同结果，所以必须用改写的提示词；改写在跑之前写定，不看结果调整。
- D1 和 D2 的特征接同样的 L4，与 A0、A3 比较，并都报告加模态独热的结果。

## 6. 表 E：L0 和提示词（需要 API，约 22 元）

以 v2 单次调用 R 为参照，每次只改一项。模型、系统提示词、温度、seed 不变，都用 TRUE/FALSE 概率，只重跑受影响的样本。

| 代号 | 变体 | 条数 | 预计 tokens |
|---|---|---:|---:|
| R | v2 单次调用，只补跑失败的 16 条 | 16 | 0.3M |
| S0 | 完整的 v1 输入和提示词，改用概率输出 | 943 | 3.3M |
| −P | 用 v1 的用户提示词和排版 | 943 | 4.9M |
| −L | 去掉附件标签 | 877 | 4.7M |
| −A1 | 原声换成截断到 8,000 字符的转写稿 | 462 | 1.3M |
| −A2 | 原声换成完整转写稿 | 462 | 2.0M |
| −S | 去掉视频音轨 | 244 | 0.9M |
| −F | 8 帧换成 16 帧 | 244 | 1.9M |
| −I | 新闻图片用原分辨率（原长边超过 1,280 的） | 334 | 2.2M |
| −D | 去掉发布日期 | 866 | 4.4M |
| −T | 没有文本模态的样本去掉标题 | 277 | 1.2M |
| N | 重复跑一次 R，测噪声底 | 180 | 0.9M |

- S0 用来和 11-07 的 v1 结果核对，判断模型服务端有没有变化。
- −A1 与 −A2 之差是截断的影响；R 与 −A2 之差是听原声的影响。
- −T 检查结果是否依赖标题。
- 各项效果相加不会正好等于总差距，剩余部分报告为交互作用。

## 7. 统计方案

- 主指标是 AUROC，次指标是 Balanced Acc. 和 Macro-F1。
- 表 A 到 C：交叉验证换 10 个划分种子重复，报告均值和范围。配对差值用按来源组（427 组）的聚类 bootstrap。之前的 bootstrap 没有按来源聚类。
- **事先定下的主要对比（4 个，Holm 校正）**：
  1. 原声：R 对 −A2；
  2. 提示词：R 对 −P；
  3. 标签：R 对 −L；
  4. 结构：两两比较对 D1（421 条三模态样本）。
- **智能体相对于模态信息的作用（A0 对 A3，加模态独热）只能算探索性**，因为我已经在同一批数据上看过 82.1%、84.6% 这些相近的结果。它只能用新的测试集确认。其余对比也都是探索性。
- 按现有结果的配对区间半宽估计：全部样本约 ±2.5 个点，含音频约 ±3.6 个点，视频约 ±5.4 个点。421 条的结构对比大约在 ±4 到 ±5 个点，这是推算，未实测。更小的作用只能说"未能分辨"。
- 失败样本：主分析用两边都成功的样本，另外报告失败按 0.5 计分的结果。
- 不根据结果改提示词、换变体或重选特征。
